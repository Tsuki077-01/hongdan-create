# 红蛋 🥚

一颗戴圆框眼镜的珊瑚橘色蛋蛋桌宠，住在 Mac 屏幕最下面。

## 安装（第一次）

1. 下载 `release/红蛋-Mac-Apple芯片.zip`（只支持 Apple 芯片 M1/M2/M3/M4… 的 Mac）。
2. 双击 zip 解压，把 `红蛋.app` 拖进「应用程序」文件夹。
3. 双击打开。因为没有苹果开发者证书，第一次会提示"无法验证开发者"：
   - 点「完成」/「好」关掉提示；
   - 打开「系统设置 → 隐私与安全性」，往下滚，看到"已阻止打开 红蛋"，点「仍要打开」，输入开机密码确认。
   - 之后就可以直接双击了。

## 怎么玩

- 平时：在屏幕底部自己出门滚一段——有时慢慢挪、有时正常滚、有时一下冲出去；偶尔滚到一半停下发呆或往回滚，偶尔原地小跳、晃一晃。蛋以外的地方鼠标能点穿。
- 眼神：鼠标靠近蛋（离蛋中心 150 点以内，约 3 厘米）时，眼珠跟着鼠标看；鼠标在附近时它不会自己乱动，正在滚也会停下。点过它之后至少 5 秒才会再自己动。
- 单击：晃一晃、咕噜一声、张嘴说话。
- 拖拽：被抓起来会害怕（眼珠缩小、o 形嘴、发抖），松手掉回屏幕底部弹一下就好了。
- 右键菜单：跟红蛋说话 / 截图 / 揍 / 扶起来 / 今天挨了 N 顿 / 静音 / 退出。
- 跟红蛋说话：右键 →「跟红蛋说话」，蛋上方会弹出一个聊天小窗，回车发送，Shift+回车换行，Esc 关掉。红蛋回的话也会冒在蛋头顶的气泡里。
  - 第一次要在小窗右上角齿轮里选用哪家、填地址，再贴那家的 API key。内置了 Claude 官方、DeepSeek、Kimi、OpenRouter，也可以选「自己填」接任何 OpenAI 兼容或 Claude 格式的接口（中转站也行）。
  - 模型不用手抄：存好 key 后会自动读出这家有哪些模型，在下拉框里选一个就存好了；也可以点「读取模型」再读一次。读不到时会说原因（key 不对 / 地址不对 / 这家不提供列表），这时在下面的输入框里手填模型名。
  - key 用 macOS 钥匙串加密，存在 `~/Library/Application Support/红蛋/key.bin`，只发给你填的那个地址，不在代码里。
  - API 按用量另外收费，跟 Claude Pro 会员分开。齿轮里还能清空聊天记录。
  - 红蛋只记得这个小窗里的聊天（存在同一个文件夹的 chat.json），看不到 Claude App 里的聊天。
- 截图：右键 →「截图」，或者按 ⌃⇧⌥S（Control + Shift + Option + S）。
  - 红蛋先举起小相机、眯一只眼"咔嚓"，屏幕边缘闪一下白光，然后躲起来；你用鼠标框选要截的区域（按空格可以改成截某个窗口，按 Esc 取消）。
  - 截好的图存在「图片」文件夹下的 `红蛋截图` 里，文件名带日期时间，同时已经复制到剪贴板，直接粘贴就行。红蛋回来会说"拍好啦"；按了 Esc 它会问"不拍了吗"。
  - 第一次截图要给红蛋"屏幕录制"权限：系统设置 → 隐私与安全性 → 屏幕录制，打开「红蛋」，然后右键退出红蛋再打开。没开权限时红蛋会用气泡提醒你。
  - 截图只存在你的 Mac 上，不会发给任何 API，也不会进记忆库。
  - 如果 ⌃⇧⌥S 被别的 App 占了，会自动换成 ⌃⇧⌥P，右键菜单「截图」旁边会显示现在用的是哪个。
- 记忆库（可选）：在小窗齿轮里填「记忆库令牌」（红蛋专用的那个，不是 claude.ai 连接器用的），点「试试连接」。
  - 红蛋会在记忆库「红蛋·自己」里写自己的工作日记：每天一条，记它和你聊了什么、截了几次图、被揍了几顿这些它亲眼看到的事，不记截图里的内容。关掉聊天小窗时写；早上 6 点以前都算前一天。
  - 每次打开、或者每天第一次说话时，红蛋会读最近几天的日记和「小克的回信」，接着前几天聊。小克回信了，它会冒个气泡告诉你。
  - 在小窗里说"跟小克说……"，红蛋会把这句话原样写进「给小克的留言」；它自己有想问小克的，也会写进去。小窗里会提示"写进给小克的信了"。
  - 聊天时它可以去记忆库翻别的书架（比如你的口味），查到的只用来聊天。它只能改自己那一格，别的书架只能看，有些书架它根本看不到。
  - 令牌和 API key 一样加密存在 `~/Library/Application Support/红蛋/` 里。不填令牌也能正常聊天和截图。
- 连续揍 3 下会 K.O.（叉叉眼、歪嘴、头顶 K.O.）。
- 今天每挨满 10 下会哭（泪汪汪、掉眼泪），扶一下或过 20 秒自己好。
- 高光永远贴着蛋左上方的边缘，像光一直从左上角打过来，蛋滚的时候高光沿着边缘滑动。

## 升级到新版本

先右键蛋 →「退出」，再把新的 `红蛋.app` 拖进「应用程序」并选择「替换」。如果又提示"无法验证开发者"，按上面第 3 步再点一次「仍要打开」。

换了新版本后，macOS 可能会把它当成新的 App：如果截图时红蛋又说没有屏幕录制权限，去 系统设置 → 隐私与安全性 → 屏幕录制，把列表里旧的「红蛋」用「−」删掉，再打开一次截图让它重新出现在列表里，打开开关，然后重开红蛋。

## 出问题时

错误会记在 `~/Library/Application Support/红蛋/error.log`（不会再弹窗打扰），把这个文件发给开发者就能定位。

## 开发

```bash
npm install
npm start          # 运行（注意先右键退出「应用程序」里的红蛋，同时只能开一个）
npm run dist:mac   # 打包 Apple 芯片版 Mac App 到 dist/
npm run release:mac   # 打包 + 本地签名（有 rcodesign 用它，没有用 codesign）+ 压缩到 release/
```

没有 rcodesign 时，打包后用系统自带的 codesign 做本地签名：

```bash
npm run dist:mac
codesign --force --deep -s - "dist/红蛋-darwin-arm64/红蛋.app"
```

自动自测（会开一个测试用的红蛋窗口，用单独的数据文件夹、本地假服务器，不碰你的 key、记忆库、图片文件夹和剪贴板）：

```bash
HONGDAN_TEST=1 npx electron . --user-data-dir=/tmp/hd-test
HONGDAN_TEST=1 HONGDAN_ONLY=talk,shot,memory npx electron . --user-data-dir=/tmp/hd-test   # 只跑新功能
```

Linux 虚拟屏幕上：`HONGDAN_TEST=1 xvfb-run -a npx electron . --no-sandbox --user-data-dir=/tmp/hd-test`

文件：`main.js` 窗口和菜单 · `pet.js` 动作表情声音 · `talk.js` 聊天小窗和调模型 · `screenshot.js` 截图 · `memory.js` 记忆库接口 · `journal.js` 工作日记和写信
