# 红蛋 🥚

一颗戴圆框眼镜的珊瑚橘色蛋蛋桌宠，住在 Mac 屏幕最下面。

## 安装（第一次）

1. 下载 `release/红蛋-Mac-Apple芯片.zip`（只支持 Apple 芯片 M1/M2/M3/M4… 的 Mac）。
2. 双击 zip 解压，把 `红蛋.app` 拖进「应用程序」文件夹。
3. 双击打开。因为没有苹果开发者证书，第一次会提示"无法验证开发者"：
   - 点「完成」/「好」关掉提示；
   - 打开「系统设置 → 隐私与安全性」，往下滚，看到"已阻止打开 红蛋"，点「仍要打开」，输入开机密码确认。
   - 之后就可以直接双击了。

## 怎么玩

- 平时：在屏幕底部自己出门滚一段——有时慢慢挪、有时正常滚、有时一下冲出去；偶尔滚到一半停下发呆或往回滚，偶尔原地小跳、晃一晃。蛋以外的地方鼠标能点穿。
- 眼神：鼠标靠近蛋（离蛋中心 150 点以内，约 3 厘米）时，眼珠跟着鼠标看；鼠标在附近时它不会自己乱动，正在滚也会停下。点过它之后至少 5 秒才会再自己动。
- 单击：晃一晃、咕噜一声、张嘴说话。
- 拖拽：被抓起来会害怕（眼珠缩小、o 形嘴、发抖），松手掉回屏幕底部弹一下就好了。
- 右键菜单：揍 / 扶起来 / 今天挨了 N 顿 / 静音 / 退出。
  - 连续揍 3 下会 K.O.（叉叉眼、歪嘴、头顶 K.O.）。
  - 今天每挨满 10 下会哭（泪汪汪、掉眼泪），扶一下或过 20 秒自己好。
- 高光永远贴着蛋左上方的边缘，像光一直从左上角打过来，蛋滚的时候高光沿着边缘滑动。

## 升级到新版本

先右键蛋 →「退出」，再把新的 `红蛋.app` 拖进「应用程序」并选择「替换」。如果又提示"无法验证开发者"，按上面第 3 步再点一次「仍要打开」。

## 出问题时

错误会记在 `~/Library/Application Support/红蛋/error.log`（不会再弹窗打扰），把这个文件发给开发者就能定位。

## 开发

```bash
npm install
npm start          # 运行
npm run dist:mac   # 打包 Apple 芯片版 Mac App 到 dist/
RCODESIGN=/path/to/rcodesign npm run release:mac   # 打包 + 本地签名 + 压缩到 release/
```
